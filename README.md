# База PDF-инструкций 2.0

Что добавлено:
- встроенный просмотр PDF на главной странице;
- версии документов;
- автор, дата загрузки и дата обновления в карточках;
- блок «Часто используемые»;
- история изменений из `changelog.json`;
- категории с иконками;
- автоматическая сортировка по алфавиту;
- админ-страница `admin.html` для загрузки PDF через GitHub API.

Важно:
- GitHub token не храните в файлах сайта.
- Пароль `admin123` — только простая блокировка интерфейса, не полноценная защита.
- Для публикации загрузите содержимое архива в корень репозитория.
