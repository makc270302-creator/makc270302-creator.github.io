# База PDF-инструкций

## Что добавлено

- Главная страница читает документы из `documents.json`.
- Карточки сортируются по алфавиту.
- Есть страница `admin.html` для добавления PDF через GitHub API.
- Репозиторий уже прописан:
  - owner: `makc270302-creator`
  - repo: `makc270302-creator.github.io`
  - branch: `main`

## Как пользоваться админкой

1. Откройте сайт.
2. Нажмите кнопку «Добавить документ».
3. Введите пароль: `admin123`.
4. Введите GitHub token.
5. Заполните название, описание, категорию, автора, дату.
6. Выберите PDF.
7. Нажмите «Загрузить документ».

## Важно про безопасность

Пароль `admin123` — это только простая блокировка кнопки. Его можно заменить в файле `admin.js` в строке:

```js
const ADMIN_PASSWORD = 'admin123';
```

Настоящую защиту даёт GitHub token. Не вставляйте token прямо в код сайта и не публикуйте его в репозитории.

## Какой GitHub token нужен

Лучше использовать fine-grained personal access token:

- Repository access: только `makc270302-creator.github.io`
- Permissions → Contents: Read and write

Token вводится на странице админки вручную.
