# База PDF-инструкций

Что добавлено:
- встроенный просмотр PDF на главной странице;
- версии документов;
- автор, дата загрузки и дата обновления в карточках;
- блок «Часто используемые»;
- история изменений из `changelog.json`;
- категории с иконками;
- автоматическая сортировка по алфавиту;
- админ-страница `admin.html` для управления PDF через GitHub API;
- атомарное сохранение PDF, карточки и истории одним Git-коммитом;
- автоматическая проверка JavaScript, JSON и наличия PDF через GitHub Actions.
- управляемые категории из `categories.json`;
- архив документов и расширенная сортировка.
- локальное избранное и компактный режим отображения;
- прямые ссылки на документы и отметка недавно обновлённых материалов.

Важно:
- GitHub token не храните в файлах сайта.
- Используйте fine-grained token только для этого репозитория с правом `Contents: Read and write`.
- Админ-страница доступна всем, но операции изменения выполняются только с действующим GitHub token.
- Формат данных описан в `documents.schema.json`, `categories.schema.json` и `changelog.schema.json`.
- Полная локальная проверка при наличии Node.js: `npm test`.

## Авторизация через Google Таблицу

1. Откройте Google Таблицу со списком пользователей.
2. Перейдите в `Расширения` -> `Apps Script`.
3. Вставьте код из `tools/google-auth-webapp.gs`.
4. Опубликуйте проект: `Развернуть` -> `Новое развертывание` -> `Веб-приложение`.
5. Права запуска: от вашего аккаунта. Доступ: все, у кого есть ссылка.
6. Скопируйте URL веб-приложения, который заканчивается на `/exec`.
7. Вставьте этот URL в `app.json` в поле `authEndpoint`.

Логин берется из столбца A листа `Пользователи`. Статус `Уволен` в столбце C блокирует вход и регистрацию. Пароль записывается в столбец F в виде SHA-256 хэша.

Если код `tools/google-auth-webapp.gs` менялся, откройте `Управление развертываниями`, нажмите редактирование развертывания, выберите `Новая версия` и снова нажмите `Развернуть`. Без этого сайт продолжит обращаться к старому коду Apps Script.
